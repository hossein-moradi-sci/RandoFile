# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-02

### Added

- In-app help, reachable from the `?` button in the header, from Settings and from `F1` anywhere in
  the app. Four tabs — Getting started, Naming pattern, Shortcuts & safety and FAQ — fully
  translated into Persian, English, French and Arabic.
- The guide is illustrated with vector mock-ups instead of screenshots, so it follows the light and
  dark theme, stays sharp at any DPI and mirrors correctly for the right-to-left languages.

### Brand

- Renamed from *Image File Randomizer* to **RandoFile** (short for *HM File Randomizer*): the app
  randomizes **any** file, so “Image” in the old name was misleading.
- New identity: three document cards swept into a fan, ringed by a segment that stands for the
  randomising motion. Shipped as a 512 px master, a transparent interface mark and a 16–256 px
  Windows icon, all generated by `tools/Generate-Logo.ps1`.
- The splash screen was rebuilt around that mark: the parts are vectors rather than a flat image, so
  they arrive one by one, settle into the logo with one soft overshoot, and then keep breathing in a
  slow endless loop. The card sits in a breathing ambient glow, each document casts a real blurred
  shadow, the ring carries a gradient stroke over a halo with a lit arrow head, and the brand name
  is set in a gradient.
- **The brand name is never translated.** `App.Title` / `App.Tagline` were removed from all four
  language files; the interface now reads the `AppInfo.Brand` and `AppInfo.Tagline` constants.
- Animated splash screen on launch: the logo scales and rotates in, a highlight sweeps across it,
  the brand and tagline fade up, then the window hands over to the main window.

### Added

- Windows desktop application (C# / .NET 8 / WPF) that runs as a native `.exe`, never in a browser.
- Folder picker with a live file count; any file type is accepted.
- Fully random Fisher-Yates shuffle before renaming, so the new order is unpredictable.
- Naming presets `Image 1, Image 2, …` and `File 1, File 2, …` plus a free custom prefix.
- Optional start number and zero padding (`Image 001.jpg`).
- Original file extensions are always preserved.
- Preview of every rename before anything is written to disk.
- Duplicate and overwrite detection: a plan with conflicts is refused, nothing is renamed.
- Two-phase rename engine (stage to temporary names, then commit) so swaps and circular renames are safe.
- Automatic rollback when a file cannot be renamed; the folder is never left half renamed.
- Undo of the last successful run, using the same safety guarantees as the rename itself.
- Progress bar, cancellable long operations, and clear success/error reporting.
- Four fully translated languages: فارسی, English, Français, العربية.
- Language switching from the Settings window, applied instantly, with right-to-left layout for Persian and Arabic.
- Light, dark and follow-Windows colour schemes.
- About window with creator details, version and a manual update check.
- GitHub Releases update check with an in-app banner, prepared for future automatic updates.
- Unit test suite covering the rename engine, planner, scanner, version comparison and resource parity.
- Crash log at `%LOCALAPPDATA%\RandoFile\crash.log` for startup failures that happen before
  a window can be shown.

### Fixed

- The main window no longer fails to open: the progress bar bound its read-only `ProgressValue` to
  `ProgressBar.Value`, which WPF binds two-way by default.
- Startup is now fully guarded, so a failure reports the problem instead of dying silently.
